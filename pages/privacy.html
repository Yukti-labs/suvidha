Privacy Architecture

How Suvidha processes files locally in your browser without transmitting data to any server.

The Core Principle: Zero Uploads

Most online converters and utility websites require you to send sensitive files (contracts, resumes, bank statements, photos) to a remote cloud server. Once uploaded, you have no visibility into how long those files are kept, who accesses them, or whether they are logged.

Suvidha works on an entirely different architecture: modern web browsers are capable of heavy computation using WebAssembly, HTML5 Canvas, and Web Cryptography. Every computation happens inside your browser's isolated sandbox on your local CPU and GPU.

Technical Verification by Category

1. PDF Tools (Compressor, Merger, Unlocker)

Powered by PDF.js and pdf-lib compiled to WebAssembly and client-side JavaScript. Files are read via the HTML5 FileReader API directly into memory buffers. Output PDFs are synthesized locally and downloaded via blob: URLs.

2. Image Tools (Compressor, Image to PDF)

Images are decoded into browser memory using createImageBitmap() and rendered onto an off-screen <canvas> element. Dimension scaling and quality re-encoding occur purely in GPU/canvas memory.

3. Financial & Math Calculators

EMI, GST, and SIP formulas are mathematical algorithms executed synchronously in standard JavaScript. SVG donut charts are calculated using SVG arc geometry without external analytics or charting servers.

4. Developer & Everyday Utilities

JSON formatting, Word Counting, QR code rendering, and Password generation run locally. Passwords use browser-native crypto.getRandomValues() for cryptographically secure randomness.

How to Verify Independently

You don't have to take our word for it. You can inspect network activity in real-time in any web browser:

  1. Press F12 or right-click anywhere and select Inspect.
  2. Click on the Network tab.
  3. Select the Fetch/XHR filter.
  4. Drop a document into PDF Compressor or Image Compressor and process it.
  5. Notice that zero network requests are transmitted. The only network activity that ever occurred was loading the static HTML, CSS, and JS files when the page first opened.

Data Storage & Accounts

Suvidha does not require an account, email address, or phone number. We do not set third-party tracking cookies or advertising pixels.

The only data stored on your device is your UI theme preference (dark/light) and your optional recent tool history stored in your own browser's localStorage, which never leaves your machine and can be cleared at any time.
